# Tidelight · drop a bottle

The browser side of Tidelight, an anonymous message-in-a-bottle for feelings. Write one true sentence, pick the colour of the glass, drop it into the same sea as the iPhone app. Wait for the tide and send a stranger a single wordless light.

Live: https://adam0thman.github.io/tidelight-web/

Every bottle is read by Claude before it can exist. Bottles are anonymous; the only identifier is a random id in your browser's local storage. Nothing here asks for a name.
